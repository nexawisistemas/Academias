# NexaWi Academias

SaaS multiempresa e multiunidade para gestão completa de academias.

## Stack

- Next.js 16 com App Router
- React 19
- TypeScript strict
- Tailwind CSS 4
- Supabase Auth, PostgreSQL e Storage
- Vercel

## Desenvolvimento local

1. Preencha a chave pública/anon do projeto Supabase em `.env.local`.
2. Nunca exponha a service role no navegador ou no repositório.
3. Execute `npm run dev`.

## Verificação

```bash
npm run lint
npm run typecheck
npm run build
```

Documentação técnica em `docs/`. Domínio planejado: `academias.nexawi.com.br`.
